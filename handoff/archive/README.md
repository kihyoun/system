# Archived local drafts

These files preserve loose source drafts and validation helpers for the 2026-10-18 Codex host handoff. They are historical snapshots, not active implementation or instructions to apply.

The paused configuration-persistence draft was deliberately left out of the current delivery: configuration management remains separate from Harvest/Seed, and adding configuration volumes still requires an explicit design decision. Do not run its patches automatically.

The validation export is an older scratch copy. Files already represented by the published source, including copies differing only by checkout line endings, were omitted. Newly archived bytes were preserved verbatim; historical documents may be outdated. Use the main handoff branch and its current English handbook for implementation.

No live credentials, generated private configuration, rendered GitLab configuration, data volumes, machine-specific disk initialization scripts, dependency caches or container archives are included. The existing development plan remains in the central System issue comments rather than being newly versioned here.
